# 콘텐츠 자산화 모델 — 1개 아이디어 → 콘텐츠 자산

하나의 오리지널 소재를 일회성으로 소비하지 않고 아래 단계로 확장하여 제작 대비 산출을 극대화한다.

```
1개 핵심 아이디어 (세계관 + 캐릭터 + 중심 갈등)
        │
        ▼
① Shorts 티저 3~5편 (캐릭터 소개, 세계관 한 장면, 후킹용 클립)
        │
        ▼
② 시리즈 에피소드 (Long-form 3~8분, 클리프행어로 연결)
        │
        ▼
③ Long-form 확장판 (에피소드 3~4개를 묶은 몰아보기/총집편)
        │
        ▼
④ 플레이리스트화 (시즌 단위로 정리, 추천 알고리즘 노출 극대화)
        │
        ▼
⑤ 후속 시즌 / 스핀오프 (반응 좋은 캐릭터 중심 신규 세계관)
```

## 단계별 실행 지침

| 단계 | 산출물 | 사용 도구 | 목적 |
|---|---|---|---|
| ① Shorts 티저 | 15~30초 세로 영상 3~5편 | ChatGPT(후킹 문구) + Higgsfield(캐릭터 클립) | 유입, 알고리즘 테스트 |
| ② 에피소드 | 3~8분 Long-form | ChatGPT(대본) + Higgsfield(장면 생성) | 시청시간, 구독 |
| ③ 확장판 | 10~20분 몰아보기 | 기존 소스 재편집 | 시청시간 극대화, 신규 제작비 0에 가까움 |
| ④ 플레이리스트 | 시즌 단위 정리 | YouTube 스튜디오 | 재방문율, 세션 시청시간 |
| ⑤ 스핀오프 | 신규 세계관 | ①부터 반복 | 채널 자산 지속 확장 |

## 판단 기준: 확장 여부 결정

에피소드 업로드 후 `database/performance_analytics.csv` 데이터를 기준으로:

- **평균 시청 지속률 60% 이상 + 구독 전환 상위 20%** → 즉시 후속편 제작, 스핀오프 후보로 등록
- **조회수는 높으나 지속률 낮음** → Shorts 유입용으로만 활용, Long-form 확장 보류
- **모든 지표 하위 30%** → 해당 세계관/포맷 폐기, 사유를 기록하고 다음 아이디어로 전환

이 모델을 통해 하나의 기획이 실패해도 티저 단계(①)에서 저비용으로 검증되며, 성공한 소재만 고비용 단계(②~⑤)로 투자가 집중된다.
