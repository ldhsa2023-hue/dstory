# 트렌드 리서치 & 실시간 대응 제작 시스템

목표: 지금 유행 중인 바이럴 포맷/사운드/후킹 구조를 빠르게 포착하여, 그대로 베끼지 않고 우리 장르(A. 시네마틱 판타지, C. 음식/요리 등)의 오리지널 콘텐츠로 재해석해 **트렌드 수명(보통 3~10일) 안에** 업로드하는 상시 운영 구조.

기존 `pipeline/production-pipeline.md`(정규 파이프라인, 기획→분석까지 1~수일)와 별도로, 트렌드 대응은 **Fast Lane(패스트레인)** 이라는 단축 경로를 사용한다.

## 1. 트렌드 레이더 (Trend Radar) — 상시 수집

| 소스 | 확인 방법 | 주기 |
|---|---|---|
| YouTube Shorts 트렌딩/급상승 | WebSearch("viral YouTube Shorts trends [현재 월/연도]"), YouTube 자체 트렌딩 탭 | 매일 1회 |
| TikTok Creative Center / 트렌딩 사운드 | WebSearch("TikTok trending sound/challenge [현재 월/연도]") | 매일 1회 |
| Higgsfield/Sora 트렌드 프리셋 | Higgsfield 앱 내 트렌드 프리셋(Sora 2 Trends 등), `mcp__higgsfield__apps_search`/`presets_show`로 신규 프리셋 확인 | 주 2~3회 |
| 경쟁/인접 채널 급성장 영상 | 우리 장르(판타지/음식/가족/비언어) 상위 채널의 최근 7일 급상승작 | 주 1~2회 |
| 자사 채널 데이터 | `database/performance_analytics.csv` 상 우리 콘텐츠 중 비정상적으로 잘 터진 영상(내부 트렌드) | 매주 리뷰 시 |

수집한 모든 후보는 즉시 `database/trend_tracker.csv` 에 기록한다(채택 여부와 무관하게 기록 — 나중에 패턴 분석용).

## 2. 트렌드 적합도 스코어 (Fast-track 판단)

각 트렌드 후보를 5개 항목 1~5점으로 즉시 채점, 합계 25점 만점.

| 항목 | 질문 |
|---|---|
| 장르 적합성 | 우리 장르(A/C/B/G)의 구조로 재해석 가능한가 |
| Higgsfield 구현 가능성 | 기존 캐릭터/에셋 재사용으로 생성 가능한가 (신규 캐릭터 설계 불필요) |
| 속도 적합성 | 24~48시간 내 기획~업로드가 가능한가 |
| 정책/저작권 리스크 (낮을수록 5점) | 원곡/원본 음원·영상 재사용 없이 구조만 차용해도 재현되는가 |
| 브랜드 적합성 | 채널 톤(판타지 세계관/푸드 비주얼)과 어긋나지 않는가 |

- **20점 이상 → Fast-track**: 즉시 Fast Lane 투입
- **13~19점 → Monitor**: `content_ideas.csv`에 일반 아이디어로만 등록, 정규 파이프라인에서 검토
- **12점 이하 → Pass**: 기록만 하고 폐기

## 3. Fast Lane 제작 경로 (목표: 스코어 확정 후 24~48시간 내 업로드)

```
트렌드 포착 & 스코어링 (10분)
      ↓
ChatGPT: 트렌드 구조 분석 + 우리 장르 재해석 (prompts/chatgpt/trend-analysis.md) — 30분
      ↓
기존 캐릭터 시트/에셋 재사용 (신규 캐릭터 설계 생략) — 0분
      ↓
Shorts 대본 1~2버전 작성 (templates/shorts_script_template.md 축약형) — 20분
      ↓
Higgsfield 생성 (기존 캐릭터 레퍼런스 + 트렌드 구조 프롬프트) — 1~3시간
      ↓
편집(자막/BGM, 가능 시 트렌드 사운드 사용 여부 확인) — 30분
      ↓
제목/썸네일 (트렌드 키워드 반영) — 15분
      ↓
업로드 + trend_tracker.csv 갱신
```

일반 파이프라인과의 차이:
- 신규 세계관/캐릭터를 만들지 않고 **기존 시리즈의 캐릭터·아트스타일을 재사용**해 속도를 확보한다.
- 정규 편성(주 2~3편 Long-form, 일 2~3편 Shorts) 사이에 **Fast Lane 슬롯을 하루 1편 예비로 확보**해 트렌드 발생 시 즉시 투입한다.
- 원본 사운드/챌린지를 "그대로 재현"하지 않는다 — 후킹 구조·페이싱·감정 곡선만 차용하고 비주얼은 100% 오리지널 캐릭터로 재해석한다(저작권/정책 리스크 제거 + 차별화 확보).

## 4. 트렌드 대응 원칙 (재확인)

1. **복제 금지, 구조만 차용**: 원본 음원/영상을 그대로 쓰지 않는다. 후킹 타이밍, 편집 리듬, 반전 구조만 우리 캐릭터로 재현한다.
2. **속도 > 완성도**: Fast Lane 콘텐츠는 정규 시리즈보다 완성도 기준을 낮추고 속도를 우선한다. 트렌드는 수명이 짧다.
3. **자산 재사용 우선**: 이미 만들어둔 캐릭터/세계관에 트렌드를 얹는다. 매번 새 세계관을 만들지 않는다.
4. **사후 검증 필수**: Fast Lane 콘텐츠도 반드시 `performance_analytics.csv`에 기록하고, 트렌드 적중률(Fast-track한 트렌드 중 실제 좋은 성과를 낸 비율)을 매주 집계해 스코어링 기준을 보정한다.
5. **트렌드 자체보다 원리를 학습**: 매주 리뷰에서 "왜 이 트렌드가 터졌는가"를 정리해 `02-recommended-strategy.md`의 상시 전략에 누적 반영한다 (일회성 소비가 아니라 장기 자산화).

## 5. 매일 운영 루틴 (요약)

| 시간대 | 작업 |
|---|---|
| 오전 | 트렌드 레이더 스캔 (WebSearch 등), `trend_tracker.csv` 기록 및 스코어링 |
| 오전~낮 | Fast-track 판정된 트렌드 있으면 Fast Lane 즉시 가동 |
| 낮~오후 | 정규 파이프라인(Long-form/Shorts) 병행 진행 |
| 저녁 | 업로드 후 초기 반응(조회수/CTR) 모니터링, 다음날 Fast Lane 여부 재판단 |
