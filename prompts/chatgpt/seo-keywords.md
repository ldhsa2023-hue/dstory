# ChatGPT 프롬프트 — SEO 키워드 & 설명문 작성

## 1. SEO 키워드 기획

```
아래 영상 주제에 대해 유튜브 SEO 키워드를 기획해라.

- 주제: [설명]
- 핵심 키워드 5개, 롱테일 키워드 10개, 관련 태그 20개로 구분해라.
- 한국어/영어 두 세트로 만들어서 글로벌 노출도 고려해라 (음식/비주얼/판타지처럼 언어 장벽이 낮은 콘텐츠는 영어 키워드 비중을 높여라).
```

## 2. 영상 설명문 작성

```
아래 정보를 바탕으로 유튜브 영상 설명문을 작성해라.

- 제목: [제목]
- 내용 요약: [요약]
- 시리즈 정보: [이전 화/다음 화/플레이리스트 링크 자리 표시]
- 구조: 첫 2줄에 핵심 키워드+궁금증 유발 문장(검색 결과·모바일에서 잘리지 않게), 이후 상세 설명, 해시태그 5~8개, 관련 영상/플레이리스트 링크
```

## 3. 콘텐츠 성과 분석 및 개선안 도출

```
아래는 최근 업로드한 영상들의 성과 데이터다: [performance_analytics.csv 데이터 붙여넣기]

분석해라:
1. CTR과 평균 시청 지속시간이 높은 영상의 공통 제목/썸네일/도입부 패턴
2. 이탈률이 높은 구간의 공통점
3. 구독 전환율이 높은 영상의 특징
4. 다음 5개 영상 기획에 반영해야 할 구체적 개선안 3가지
```
