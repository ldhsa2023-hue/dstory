# ChatGPT 프롬프트 — 제목 & 썸네일 문구 개발

## 1. 제목 후보 생성

```
아래 영상 내용에 대해 클릭률 높은 제목 후보 15개를 만들어라.

- 영상 내용: [요약]
- 포맷: [Shorts / Long-form]
- 3개 카테고리로 나눠라: 궁금증 유발형 / 숫자·리스트형 / 감정 자극형
- 각 제목은 40자 이내(모바일 노출 기준), 낚시성이 아니라 실제 내용과 일치해야 한다.
- 시리즈물이면 "1화", "EP.1" 등 회차 표기를 포함한 버전도 3개 만들어라.
```

## 2. 썸네일 문구 & 구도

```
아래 제목/내용에 어울리는 썸네일 문구(3~6단어) 후보 10개와, 각 문구에 어울리는 이미지 구도(인물 표정, 배치, 텍스트 위치, 색상 대비)를 함께 제안해라: [제목/내용]

Higgsfield로 썸네일용 정지 이미지를 생성할 수 있도록 이미지 생성 프롬프트도 3개 작성해라.
```

## 3. 제목/썸네일 A-B 테스트 설계

```
아래 영상에 대해 서로 다른 심리적 훅(호기심/이득/공포/유머)을 사용한 제목-썸네일 조합 4세트를 설계해라: [영상 내용]
각 세트가 타겟팅하는 시청자 유형도 설명해라.
```
