# ChatGPT 프롬프트 — 쇼츠 후킹 문구 개발

## 1. Hook 문구 대량 생성

```
아래 영상 소재에 대해 1~3초 안에 스크롤을 멈추게 할 Hook 문구/장면 아이디어를 20개 만들어라.

- 소재: [설명]
- 카테고리별로 5개씩 나눠라:
  1) 질문형 ("이거 진짜일까?", "왜 이렇게 됐을까?")
  2) 반전 예고형 ("마지막에 반전이 있습니다")
  3) 비주얼 임팩트형 (등장하자마자 시선을 끄는 장면 묘사)
  4) 공감/궁금증 유발형 ("이런 적 있으신가요?")
- 각 문구가 왜 효과적인지 1줄 이유를 붙여라.
```

## 2. 첫 1초 비주얼 설계

```
아래 Hook 문구에 어울리는 "영상 시작 1초"의 비주얼을 구체적으로 묘사해라 (Higgsfield 프롬프트로 바로 쓸 수 있게): [Hook 문구]

포함할 요소: 인물/사물의 위치, 움직임, 카메라 거리, 색감, 감정 톤
```

## 3. 시청 지속률 개선용 중간 후킹

```
아래 대본의 5~10초 구간, 15~20초 구간에 이탈을 막을 미니 후킹 요소(질문, 예고, 비주얼 전환)를 각각 2개씩 제안해라: [대본 붙여넣기]
```
