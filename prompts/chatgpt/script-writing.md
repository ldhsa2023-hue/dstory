# ChatGPT 프롬프트 — 대본 작성 & 스토리텔링

## 1. Long-form 에피소드 대본

```
너는 AI 생성 영상용 대본 작가다. 아래 조건으로 3~8분 분량 대본을 작성해라.

- 세계관/캐릭터: [설명]
- 이번 화 로그라인: [1문장]
- 구조: 1~3초 Hook → 상황 제시(15~30초) → 전개 → 클라이맥스 → 클리프행어/마무리
- 장면(Shot) 단위로 나눠라. 각 장면마다:
  1) 장면 번호 및 길이(초)
  2) 화면에 보이는 것 (Higgsfield 프롬프트 작성에 쓸 수 있도록 구체적으로: 인물, 행동, 배경, 카메라 앵글, 조명, 분위기)
  3) 내레이션/대사
  4) 자막 텍스트
- 시청 이탈이 잦은 구간(전개 중반)에 반전 요소나 질문을 배치해라.
- 마지막 3초는 다음 화를 궁금하게 만드는 클리프행어로 끝내라.
```

## 2. Shorts 대본 (15~30초)

```
너는 Shorts 대본 작가다. 아래 소재로 15~30초 세로 영상 대본을 3개 버전으로 작성해라.

- 소재: [설명]
- 각 버전마다 1~3초 안에 시청자를 붙잡는 Hook 문장/장면을 다르게 시도해라 (질문형, 반전형, 비주얼 임팩트형)
- 장면은 3~5개 샷으로 구성, 각 샷은 3~6초
- 마지막 장면에 "완주 유도" 요소(결과 공개, 반전, 다음 이야기 예고) 포함
- 각 버전 하단에 Higgsfield 프롬프트 초안도 함께 작성해라
```

## 3. 동일 소재 다중 버전 제작

```
아래 대본/장면을 기반으로 A/B 테스트용 변형 버전 3개를 만들어라: [대본 붙여넣기]

변형 축:
1) Hook 문장만 다르게
2) 톤(코믹/진지/미스터리)만 다르게
3) 결말(해피엔딩/클리프행어/반전)만 다르게

각 변형이 어떤 시청자 반응을 유도할 것으로 예상하는지 함께 설명해라.
```
