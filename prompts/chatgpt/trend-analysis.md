# ChatGPT 프롬프트 — 트렌드 분석 & 우리 장르 재해석

`strategy/04-trend-response-system.md` 의 Fast Lane 2단계(트렌드 구조 분석 + 재해석)에서 사용.

## 1. 트렌드 원본 구조 분석

```
아래는 최근 바이럴 중인 트렌드/포맷/사운드다: [트렌드 설명, 출처 링크, 원본 예시 붙여넣기]

이 트렌드를 구조적으로 분석해라:
1. 왜 지금 바이럴한가 (시의성/감정/유머/공감 포인트)
2. 핵심 후킹 구조 (몇 초에 무슨 일이 일어나는가)
3. 반복되는 편집/연출 패턴 (컷 타이밍, 반전 위치, 사운드 싱크 포인트)
4. 시청자가 참여/공유하고 싶어지는 이유
5. 이 트렌드의 예상 수명 (며칠~몇 주)

원본을 그대로 재현하지 말고, 구조만 추출해라.
```

## 2. 우리 장르로 재해석 (핵심 단계)

```
위에서 분석한 트렌드 구조를, 아래 우리 콘텐츠에 이식해라.

- 우리 시리즈/캐릭터: [기존 캐릭터 시트 요약]
- 장르: [시네마틱 판타지 / 음식·요리 / 가족 애니메이션 / 비언어]
- 조건:
  1. 원본 음원/영상을 그대로 쓰지 않는다 — 후킹 타이밍과 감정 곡선만 차용한다.
  2. 기존 캐릭터/세계관을 그대로 재사용한다 (신규 캐릭터 설계 금지).
  3. 24~48시간 내 제작 가능한 분량(15~30초 Shorts)으로 구성한다.

출력: 로그라인 1줄 + 3~5개 샷 구성(Higgsfield 프롬프트로 바로 쓸 수 있게 구체적으로) + 자막/대사 + 예상 왜 이게 터질지에 대한 근거
```

## 3. Fast Lane 축약 대본 생성

```
위 재해석안을 바탕으로 `templates/shorts_script_template.md` 형식의 축약 대본을 즉시 작성해라.
제작 시간이 없으므로 샷 수는 최대 5개, 각 샷의 Higgsfield 프롬프트까지 함께 출력해라.
제목 후보 3개, 트렌드 관련 키워드/해시태그 5개도 함께 제시해라.
```

## 4. 트렌드 적중률 회고 (주간)

```
아래는 이번 주 Fast-track한 트렌드 대응 영상들의 성과 데이터다: [trend_tracker.csv + performance_analytics.csv 관련 행 붙여넣기]

분석해라:
1. 어떤 유형의 트렌드(사운드형/포맷형/챌린지형)가 우리 장르와 가장 잘 맞았는가
2. 스코어링 기준(장르적합성/속도/리스크/브랜드) 중 실제 성과와 상관관계가 높은 항목은 무엇인가
3. 다음 주 트렌드 스코어링 기준을 어떻게 조정해야 하는가
```
