# ChatGPT 프롬프트 — 아이디어 발굴 & 경쟁 콘텐츠 분석

## 1. 신규 아이디어 발굴

```
너는 유튜브 AI 콘텐츠 기획 전문가다. 아래 조건을 만족하는 콘텐츠 아이디어 10개를 제안해라.

- 장르: [시네마틱 판타지 시리즈 / 음식·요리 / 가족 애니메이션 중 택1]
- 제작 방식: Higgsfield AI로 이미지/영상 생성, 캐릭터 일관성 유지 가능해야 함
- 목표: Shorts는 15~30초, Long-form은 3~8분
- 각 아이디어마다 다음을 포함:
  1) 한 줄 로그라인
  2) 타겟 시청자
  3) 1~3초 Hook 아이디어
  4) 시리즈로 확장 가능한 이유
  5) 예상 제작 난이도(상/중/하)

기존 인기 채널을 그대로 베끼지 말고, 오리지널 세계관/캐릭터로 제안해라.
```

## 2. 경쟁 콘텐츠 구조 분석

```
아래는 [경쟁 채널/영상 URL 또는 설명]의 특징이다: [붙여넣기]

이 콘텐츠를 다음 관점에서 분석해라:
1. 사람들이 클릭하는 이유 (썸네일/제목 요소)
2. 사람들이 끝까지 보는 이유 (전개 구조, 페이싱)
3. 댓글을 남기는 이유
4. 구독하는 이유
5. 다음 편을 기다리는 이유
6. 반복해서 보는 이유

그리고 이 구조를 AI 생성 영상(Higgsfield)으로 재현 가능한 형태로 재설계해라.
직접 복제가 아니라 "구조"만 차용한 오리지널 기획안을 제시해라.
```

## 3. 시리즈 설계

```
[세계관/캐릭터 설명]을 기반으로 10부작 시리즈를 설계해라.
각 화마다:
- 제목
- 로그라인 (1문장)
- 클리프행어 포인트
- 이전 화와의 연결 고리
- Shorts로 뽑을 수 있는 하이라이트 장면 1개

시청자가 다음 화를 기다리게 만드는 구조를 우선시해라.
```
