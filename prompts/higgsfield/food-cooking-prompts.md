# Higgsfield 프롬프트 — 음식/요리 AI 영상 (Shorts 유입 엔진)

비언어·글로벌 확장에 최적화된 포맷. 15~30초, 하루 2~3편 대량 생산을 목표로 한다.

## 1. 클로즈업 조리 과정 (Hook용 1~2초)

```
extreme close-up shot of [음식 재료/요리 과정: 예) sizzling butter melting on a steak],
steam rising, glistening texture, warm cinematic lighting, shallow depth of field,
food photography style, mouth-watering detail, slow motion feel, 4k macro shot
```

## 2. 조리 액션 시퀀스

```
hands [행동: chopping / pouring sauce / flipping pancake] on [음식],
top-down shot / 45-degree angle, natural kitchen lighting, satisfying motion,
crisp sound-implying visual (splash, sizzle, crunch texture visible), realistic food styling
```

## 3. 완성 비주얼 (엔딩/리워드 샷)

```
final plated shot of [완성 요리], overhead flat lay / hero angle,
garnish detail, steam and glossy texture, warm golden lighting,
restaurant-quality food styling, satisfying reveal, vertical 9:16 framing
```

## 4. ASMR/루프 반복 시청 유도 샷

```
looping close-up of [반복 가능한 행동: 예) honey drizzling / cheese pull / knife slicing],
smooth continuous motion, glossy texture highlight, soft ambient lighting,
seamless loop feel, satisfying visual rhythm
```

## 제작 팁
- 세로(9:16) 프레이밍 고정, 얼굴 없이 손/재료 위주로 구성하면 언어 자막 없이도 해외 시청자에게 소구 가능.
- 시리즈화: "매일 다른 재료로 같은 요리 만들기", "3가지 소스 비교" 등 반복 포맷을 만들어 캐릭터 시트 없이도 시리즈성 확보.
- Long-form 확장 시: 같은 회차 5~10개를 이어붙여 "N가지 요리 몰아보기"로 재구성.
