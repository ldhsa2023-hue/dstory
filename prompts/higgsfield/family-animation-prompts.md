# Higgsfield 프롬프트 — 가족·일상 AI 애니메이션 시트콤

캐릭터 고정 + 짧은 에피소드 구조로 반복 제작 효율이 높은 보조 트랙. A(시네마틱 판타지) 성과가 검증된 후 확장 후보.

## 0. 캐릭터 시트 (가족 구성원별 1회 생성)

```
[캐릭터 이름/역할: 예) 막내딸, 아빠], [나이/외형/성격이 드러나는 표정],
consistent character design, cute stylized animation look,
turnaround view, soft flat lighting, [고정 아트 스타일: 예) 3D pixar-like / 2D flat animation]
```

## 1. 일상 에피소드 장면

```
[캐릭터]가 [일상 행동: 아침을 준비한다 / 실수를 한다 / 가족과 대화한다],
in [집 안 배경], warm cozy lighting, expressive exaggerated pose,
comedic timing implied through pose, [고정 아트 스타일]
```

## 2. 코믹 리액션 샷 (구독 유도 포인트)

```
[캐릭터]의 과장된 놀람/웃음 표정 클로즈업, big expressive eyes,
comedic squash-and-stretch feel, bright saturated colors, [고정 아트 스타일]
```

## 3. 에피소드 마무리 (따뜻한 결말)

```
가족 전체가 [상황: 함께 웃는다/화해한다] 장면, wide shot,
warm sunset or cozy indoor lighting, heartwarming composition, [고정 아트 스타일]
```

## 제작 팁
- 매 에피소드 1~2분 내외로 짧게, 기승전결을 단순화(공감 포인트 1개 + 웃음 포인트 1개).
- 특정 캐릭터(막내/반려동물 등)가 반응이 좋으면 해당 캐릭터 스핀오프 Shorts로 즉시 확장.
